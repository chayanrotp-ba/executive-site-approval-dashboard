# Executive Site Approval Dashboard

ระบบพิจารณาจุดติดตั้งสำหรับผู้บริหาร รันบน localhost และเก็บข้อมูลบนเครื่อง

## เริ่มใช้งาน

ติดตั้ง Node.js 22 ขึ้นไป แล้วดับเบิลคลิก **เปิด-Executive-Local.cmd** หรือรัน:

```sh
node scripts/executive-server.cjs
```

เปิด http://127.0.0.1:4184/ ระบบรันได้โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## ความสามารถ

- 85 จุดติดตั้ง รวมตัวแทนจังหวัด 20 จุดจาก 20 จังหวัด
- ตัวกรองลุ่มน้ำ จังหวัด ตัวแทนจังหวัด และช่วงคะแนน
- อนุมัติทีละจุดหรืออนุมัติทั้งหมดตาม Filter
- Master ประวัติการบันทึก พร้อมเวลาประเทศไทย ดูรายละเอียด ลบ และส่งออก JSON
- Master รูปภาพ อัปโหลดหลายรูปแยกจุดติดตั้ง และแสดงใต้สถานะการพิจารณาพร้อมก่อนหน้า–ถัดไป
- รีเฟรชเริ่มการเลือกรอบใหม่ ประวัติและรูปยังอยู่

ข้อมูลใช้งานจริงเก็บใน `data/executive-master/` และไม่รวมใน Git ควรสำรองโฟลเดอร์นี้ด้วย

## พัฒนาและทดสอบ

```sh
npm install
npx playwright install chromium
npm run build
npm test
```

การทดสอบใช้พอร์ต 4185 และ Master แยกใน tmp การบันทึกและอัปโหลดใช้ Node.js API จึงต้องรันผ่าน localhost; GitHub Pages ไม่รองรับ API นี้

## เปิดดูผ่าน GitHub Pages

GitHub Pages แสดงข้อมูล 85 จุด พร้อมตัวกรอง รายละเอียด และการเลือก/ยกเลิกอนุมัติตามไฟล์ตัวอย่าง มีสรุปยอดรายจังหวัด เป้าหมาย 70 จุด และอนุมัติทั้งหมดตาม Filter ผลการเลือกบน Pages มีผลเฉพาะรอบที่เปิดอยู่ รีเฟรชเริ่มรอบใหม่ ไม่บันทึกในเบราว์เซอร์หรือ Master ของ localhost การบันทึก Master และจัดการรูปใช้ผ่าน localhost ประวัติและรูปที่อัปโหลดใน localhost ยังเก็บอยู่บนเครื่องที่ใช้งานและไม่รวมในเว็บ Pages

สร้างไฟล์ Pages ด้วย `node scripts/build-executive-pages.cjs` และตรวจด้วย `node scripts/test-executive-pages.cjs` Workflow `.github/workflows/pages.yml` เผยแพร่ผลสร้างบน branch main หลังเปิด GitHub Pages ใน repository

รายละเอียดแหล่งข้อมูล คะแนนไร่โคก และการจัดการประวัติ: [คู่มือระบบ](docs/executive-local.md)
