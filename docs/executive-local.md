# Executive Dashboard localhost

หลังดาวน์โหลดหรือ clone repository ให้ติดตั้ง Node.js 22 ขึ้นไป แล้วดับเบิลคลิกตัวเปิดด้านล่าง หรือรัน `node scripts/executive-server.cjs` จากโฟลเดอร์โปรเจกต์ ระบบรันได้โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

สร้าง HTML ใหม่จากต้นฉบับที่รวมอยู่ใน repository ได้ด้วย `node scripts/create-executive-history.cjs` ต้นฉบับอยู่ใน `assets/executive/source-v12.html`

สำหรับผู้พัฒนา: ทดสอบด้วย `node scripts/test-executive-local.cjs` หลังติดตั้ง Playwright (`npm install --no-save playwright` และ `npx playwright install chromium`) การทดสอบใช้พอร์ต 4185 และ Master แยกใน tmp จึงไม่แก้ข้อมูลใช้งานจริง

GitHub เก็บซอร์สโค้ดและข้อมูลตั้งต้น ระบบบันทึก Master และอัปโหลดรูปใช้ Node.js บนเครื่องที่รันเซิร์ฟเวอร์ หากเปิด HTML ผ่าน GitHub Pages จะไม่สามารถใช้ API สำหรับบันทึก Master หรืออัปโหลดรูปได้

ดับเบิลคลิก `เปิด-Executive-Local.cmd` เพื่อเริ่มเซิร์ฟเวอร์และเปิด http://127.0.0.1:4184/ ตัวเปิดจะใช้เซิร์ฟเวอร์เดิมเมื่อระบบเปิดอยู่แล้ว

เลือกผลการพิจารณาแล้วกด **บันทึกลง Master** แต่ละรอบเก็บครบ 85 จุดและใช้เวลาปัจจุบันจากเซิร์ฟเวอร์ แสดงเวลาไทย รีเฟรชหน้าเว็บเพื่อเริ่มการเลือกรอบใหม่ ประวัติยังอยู่ใน Master ดูรายละเอียดและลบแต่ละรอบได้จากแท็บ Master หรือ http://127.0.0.1:4184/master ประวัติเดิม 84 จุดเก็บตามผล ณ เวลาบันทึกเดิม ไม่เพิ่มแถวใหม่ย้อนหลัง

ประวัติจริงเก็บแยกเป็นไฟล์ JSON ต่อรอบใน `data/executive-master/` จึงยังอยู่หลังปิดเซิร์ฟเวอร์ เปลี่ยนเบราว์เซอร์ หรือล้างข้อมูลเว็บไซต์ สำรองทั้งโฟลเดอร์นี้หรือใช้ปุ่มส่งออก JSON

ตารางมีตัวกรองลุ่มน้ำ จังหวัด ประเภทสถานที่ “ตัวแทนจังหวัด” และช่วงคะแนน ใช้ร่วมกันได้ ตัวแทนจังหวัดครบ 20 แห่งตามรายชื่อใน `scripts/executive-representatives.json` จุดไร่โคกเพิ่มคืนจาก `executive_site_candidate_dashboard_v8.html` ใน Downloads ตำแหน่ง `DATA.classA[14]` โดยเก็บข้อมูลที่สกัดใน `data/executive-supplemental.json` ใช้ SpatialScore 71.83 และคำนวณ FinalScore ด้วยสูตร 50:50 ของระบบปัจจุบันเป็น 70.915 จุดนี้ไม่ปรากฏในไฟล์ v12 จึงทำให้รายการรวมปัจจุบันเป็น 85 จุด รหัส `LOCAL-PBI-RAIKOK` เป็นรหัสอ้างอิงภายในสำหรับผูกข้อมูล/รูป ไม่ใช่รหัสสถานีทางการ ลุ่มน้ำและรหัสสถานีทางการยังไม่มีในแหล่งอ้างอิงและแสดงว่าไม่พบ

ประวัติจากการเปิด HTML แบบไฟล์เดิมเก็บอยู่ในเบราว์เซอร์ของไฟล์เดิมและยังไม่ย้ายเข้าสู่ Master ของ localhost โดยอัตโนมัติ

ปุ่ม **อนุมัติทั้งหมดตาม Filter** อนุมัติเฉพาะรายการที่ตรงกับตัวกรองปัจจุบันทั้งหมด เมื่ออนุมัติครบแล้วปุ่มเปลี่ยนเป็น **ล้างอนุมัติทั้งหมดตาม Filter** กดอีกครั้งเพื่อล้างเฉพาะรายการที่กรองอยู่ ผลที่เลือกไว้นอกตัวกรองยังคงเดิม ถ้าไม่เลือกตัวกรองจะสลับอนุมัติ/ล้างทุกจุด ปุ่มปิดใช้งานเมื่อไม่มีรายการตรงตัวกรอง หรือช่วงคะแนนไม่ถูกต้อง หลังเลือกแล้วให้กดบันทึกลง Master เพื่อเก็บผลรอบนั้น

ระบบใช้ Node.js โดยไม่ต้องติดตั้งแพ็กเกจเพิ่ม รันด้วยคำสั่ง `node scripts/executive-server.cjs` ได้เช่นกัน เปิดรับการเชื่อมต่อเฉพาะเครื่องนี้ที่ 127.0.0.1:4184

Master มี 2 เมนู: **Master ประวัติการบันทึก** และ **Master จัดการการแสดงรูป** เมนูรูปเปิดตรงที่ http://127.0.0.1:4184/images เลือกจุดติดตั้งแล้วเลือกรูปได้หลายไฟล์และกดอัปโหลด รองรับ JPG, PNG, GIF และ WebP ไม่เกิน 10 MB ต่อรูป รูปแสดงเฉพาะรายละเอียดของจุดนั้นใต้สถานะการพิจารณา พร้อมปุ่มก่อนหน้า–ถัดไป เรียงตามลำดับอัปโหลด และลบหรือเปลี่ยนจุดติดตั้งของรูปได้จากหน้า Master รูปเก็บใน `data/executive-master/images/` สำรองโฟลเดอร์นี้พร้อมประวัติได้ รูปที่อัปโหลดไว้ก่อนมีการผูกจุดติดตั้งยังอยู่ในรายการ “ยังไม่ผูกจุดติดตั้ง” ให้เลือกจุดของรูปแล้วกดบันทึกจุดติดตั้ง รูปไม่ได้แนบสำเนาเข้าแต่ละประวัติการอนุมัติ
